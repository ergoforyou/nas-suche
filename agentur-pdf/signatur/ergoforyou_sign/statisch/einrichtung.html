1 Zugang für Kunden (von außen)

Ein Tunnel macht nur die Unterschriftsseite sicher über HTTPS erreichbar – ohne Portfreigabe am Router. Die Einrichtung und alle Daten bleiben im Büronetz.

Eigene Adresse verwenden (fortgeschritten)

Nur nötig, wenn die Kundenseite statt über den Tunnel über eine eigene Domain oder den DSM-Reverse-Proxy erreichbar ist.

2 HubSpot verbinden optional

Status:

So bekommen Sie den Zugriffsschlüssel (5 Minuten, einmalig)
  1. In HubSpot oben rechts das Zahnrad (Einstellungen) öffnen.
  2. Links Integrationen → Private Apps (in neuer Oberfläche: Entwicklung → Legacy-Apps) → Private App erstellen, Name „Ergoforyou Sign“.
  3. Reiter Bereiche: crm.objects.contacts.read, crm.objects.contacts.write, crm.objects.deals.read, crm.objects.deals.write, files anhaken.
  4. App erstellen → Token anzeigen → kopieren und unten einfügen.

Der Schlüssel läuft nicht ab und bleibt nur hier auf dem NAS. Klappt eine Ablage einmal nicht (z. B. Internet weg), holt der Dienst sie automatisch nach.

3 Ergoforyou PDF verbinden

In Ergoforyou PDF: Schützen → Zur Unterschrift senden (oder oben rechts Beta MK I → Online-Unterschrift) → Code einfügen → Verbinden. Mit gemeinsamem Einstellungsordner auf dem NAS reicht das an einem PC.
