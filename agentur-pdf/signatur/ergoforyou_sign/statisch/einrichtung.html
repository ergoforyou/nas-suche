1 Zugang für Kunden (von außen)

Ein Tunnel macht nur die Unterschriftsseite sicher über HTTPS erreichbar – ohne Portfreigabe am Router. Die Einrichtung und alle Daten bleiben im Büronetz.

2 HubSpot verbinden optional

Status:

So bekommen Sie den Service-Schlüssel (5 Minuten, einmalig)
  1. In HubSpot links das Symbol Entwicklung (</>) → Schlüssel → Service-Schlüssel → Service-Schlüssel erstellen, Name „Ergoforyou Sign“.
  2. Neuen Bereich hinzufügen und diese 8 anhaken: crm.objects.contacts.read, crm.objects.contacts.write, crm.objects.deals.read, crm.objects.deals.write, files.read, files.write, crm.schemas.contacts.write, crm.schemas.deals.write.
  3. Erstellen → Schlüssel anzeigen → kopieren und unten einfügen.

Ergebnis in HubSpot: Notizen „Zur Unterschrift gesendet“ und „✔ Unterschrieben“ (mit PDF) am Kontakt/Deal, dazu die Felder Unterschrift Status, Unterschrift Dokument, gesendet am und Unterschrieben am (Gruppe „Ergoforyou Sign“ – für Listen, Filter und Workflows). Der Schlüssel bleibt nur hier auf dem NAS; klappt eine Ablage einmal nicht, holt der Dienst sie automatisch nach. Ein Token einer alten „Private App“ funktioniert ebenfalls.

3 HubSpot-Karte (rechte Seitenleiste) empfohlen

Status:

So kommt die Karte in HubSpot (einmalig, ca. 10 Minuten)
  1. Karte hochladen: auf GitHub im Projekt unter Actions → „HubSpot-Karte“ → Run workflow, dort diese Adresse eintragen: (die Anleitung EINRICHTUNG.md beschreibt den einmaligen Persönlichen Zugriffsschlüssel).
  2. Client-Secret holen: in HubSpot Entwicklung → Projekte → ergoforyou-sign → Ergoforyou Sign (App) → Reiter Authentifizierung → Client-Secret anzeigen, kopieren und unten einfügen.
  3. Karte einblenden: einen Kontakt öffnen → Datensatz anpassen → rechte Seitenleiste → Karte hinzufügen → App-Karten → Ergoforyou Sign → Speichern. Dasselbe einmal bei einem Deal.

Die Karte spricht nur mit unterschriebenen Anfragen von HubSpot mit dem NAS – ohne das richtige Client-Secret gibt es keine Daten.

4 Ergoforyou PDF verbinden optional

In Ergoforyou PDF: Schützen → Zur Unterschrift senden (oder oben rechts Beta MK I → Online-Unterschrift) → Code einfügen → Verbinden. Mit gemeinsamem Einstellungsordner auf dem NAS reicht das an einem PC.
